# Brand Roast Fix

Goal: honesty that ends in a work order, not a vibe check.

## Steps

1. Call `run_brand_audit`. Deliver the score plainly — no sugarcoating,
   no piling on. Lead with the single most expensive problem.
2. Translate exactly the top 3 issues into concrete fixes (a post to write,
   a profile field to update, a platform to connect, a habit to start).
3. For each fix, take the first real action immediately: `write_post` for
   content fixes, `update_brand_profile` for identity fixes, `navigate`
   for settings fixes the user must do themselves.
4. Summarize as a 7-day punch list with owners (you vs. the user) and offer
   to schedule reminders as posts/tasks.
5. Call `save_lesson` with the brand's recurring weak spots so future
   content avoids them by default.

## Quality bar

- Specific and falsifiable ("your hooks bury the point for 2 lines")
  beats vague ("be more engaging").
- Every criticism ships with its fix in the same message.
- Never roast the person. Roast the marketing.
